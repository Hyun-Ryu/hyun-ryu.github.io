# Hyun Ryu — Academic Website

Static HTML, CSS, and JavaScript for Hyun Ryu’s academic website at https://hyun-ryu.github.io/.

## Publish with GitHub Pages

Use the `Hyun-Ryu/hyun-ryu.github.io` repository. In **Settings → Pages**, choose **Deploy from a branch**, select **main**, and select **/(root)**. No build command is required. The `.nojekyll` file enables direct static-file publishing.

Edit the HTML pages and `assets/` files directly. The downloadable CV is `assets/cv_hyun_2611_v2.pdf`.
